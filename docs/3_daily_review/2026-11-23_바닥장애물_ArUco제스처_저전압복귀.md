### 1.2 ArUco 숫자 카드 + 한 손 Nav2/자동순찰 제어
- **인식 구조 전환 (`src/jetson/gesture_node.py`)**:
  - 초기 `MediaPipe Hands` 손가락 카운팅은 터틀봇3 낮은 카메라 위치 특성상 근거리·가독 제약이 커 **손가락 카운팅을 제거**하고, 원거리(`3~4m`)·저지연(`~5ms`) **OpenCV ArUco (`DICT_4X4_50`) 숫자 카드 + 1-Hand 단순 제스처 하이브리드**로 재설계 (`mediapipe==0.10.18` 컨테이너 격리 설치, 기존 `numpy 1.26.4`·`opencv`·`torch`·`ultralytics` 무손상).
  - **ArUco 카드**: `ID 0` = `ESTOP` (`0.25s`, 쿨다운 `2s`), `ID 1~10` = `GOTO_WP` (`0.8s`, 쿨다운 `4s`). A4 인쇄용 카드 11장 PDF([`docs/aruco_wp_cards.pdf`](../../docs/aruco_wp_cards.pdf)) 생성.
  - **한 손 제스처** (`model_complexity=1`, `mp_frame_stride=2`): 양손/주먹 인식률 저하를 반영해 앞·뒷면 무관한 **✋ 한 손 활짝 펼침(`1.5s` ➔ `NAV2_STOP`)**, **👍 한 손 엄지척(`2.0s` ➔ `NAV2_START`)**으로 단순화 (`PID 816` 가동 중).
- **제어 연동 (`patrol_node.py`, `web_monitor_server.py`, `yolo_overlay.js`)**:
  - `patrol_node.py`: `/gesture/cmd` 수신 시 `ESTOP`(Goal 취소·정지·TTS) 및 `GOTO_WP`(등록 전체 WP 중 1~10 단일 이동·도착 TTS) 실행.
  - `web_monitor_server.py`: `NAV2_START` 수신 시 Nav2 기동 ➔ `auto_localizer` 위치 추정 완료 및 `/patrol/set_enabled` 준비 대기(최대 75초) 후 자동 순찰 ON + TTS(`"자동 순찰을 시작합니다."`); `NAV2_STOP` 수신 시 대기 취소 + Nav2 종료 + TTS.
  - `yolo_overlay.js`: `/api/yolo` 경유 우측 상단 제스처/카드 진행률 HUD 배지 렌더링.

### 1.3 사람 근접 감지/추종 통일 & OpenCR `10.5V` 저전압 복귀 · 단절 UI 교정
- **사람 감지·추종 통일 (`vlm_service_node.py`, `patrol_node.py`, `src/jetson/AGENTS.md`)**:
  - `1.7m (176px) / 20s / 40s` ➔ **`1.2m (h >= 250px) / 3초 확정 / 30초 추종 / 50초 쿨다운`**으로 양쪽 일치 (`vlm_service_node.py` `PID 1166` 재기동 반영).
- **OpenCR `10.5V` 저전압 자동 복귀 (`patrol_node.py`, `web_monitor_server.py`, `map.html`)**:
  - `/battery_state` `9.0V < V <= 10.5V` `5.0초` 연속 지속 시 1회 래치(`low_volt_returning`) 후 `patrol.dock` 좌표로 Nav2 자율 복귀(`DOCK_RETURN`/`DOCKED` + TTS, `11.5V` 회복 시 래치 해제).
  - WebUI `/map` WP 탭에 `🔌 현재 위치 충전소 지정 (10.5V 복귀)` 버튼(`action: set_dock`) 추가 및 YAML 저장 시 기존 `dock` 보존.
- **OpenCR 단절 시 상단 전압바 버그 교정 (`web_monitor_server.py`, `map.html`, `index.html`)**:
  - `turtlebot3_ros`가 `Failed to read[[TxRxResult] There is no status packet!]` 후 종료되었을 때 `status`만 `NO_CONNECT`로 바뀌고 `voltage` 캐시(`11.56V`)가 남아 상단바 조건(`status === 'OFFLINE'`)을 통과하던 버그 규명.
  - `NO_CONNECT` 전환 시 `voltage=0.0`, `is_switch_on=False`, `torque=False`로 초기화하고 `map.html`/`index.html` 상단바 조건을 `status !== 'ONLINE'`으로 교정해 단절 즉시 **`🔴 OpenCR OFF`** 표출.
