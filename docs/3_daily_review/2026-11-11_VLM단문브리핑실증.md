## 2. 세부 엔지니어링 수행 내역

### 1) 3-Tier 무인 브리핑 풀 루프 실시간 현장 실증
* **분산 통신 계통 실측 검증**:
  - **Tier 1 (Raspberry Pi 5)**: CSI 카메라 압축 영상(`/camera/image_raw/compressed`, Q90) 및 현장 USB 스피커(`pi5_speaker_node`) 대기 확인.
  - **Tier 2 (Jetson Orin Nano)**: `my_ros2_robot:humble` 내 Qwen2-VL 4-bit NF4 모델 GPU VRAM(1.42GB) 상주 및 실시간 YOLO11n 동시 가동 확인.
  - **DDS 전송 지연**: Jetson 발행(`.845s`) ➔ Pi 5 수신(`.855s`) 간 **네트워크 레이턴시 단 9.2ms(0.009초)** 기록.
  - **VLM 추론 속도**: 4-bit NF4 양자화 상태에서 1회 질의 지연 시간 **10.01s ~ 10.79s** 안정적 도출.

### 2) 간결한 단문 요약(사물+개수) 프롬프트 개편
* **개선 배경**:
  - 기존 프롬프트는 LLM 특유의 번호 매기기(`1. 테이블... 2. 의자...`)와 사족 서술로 인해 발화 시간이 늘어지고 토큰 제한에 걸려 끝 문장이 잘리는 비효율 발생.
* **조치 내역**:
  - `src/jetson/vlm_service_node.py`의 기본 프롬프트를 직관적인 단문 1문장 형식으로 개편:
    > *"눈앞에 보이는 주요 사물의 이름과 대략적인 개수를 파악하여, 상세 설명, 번호 매기기, 좌표값(괄호) 없이 '책상 하나와 의자 두 개가 보입니다'처럼 자연스럽고 간결한 한국어 한 문장으로만 말해줘."*

### 3) 2-Tier 비전 그라운딩 좌표 노이즈 방탄 필터 구축
* **발생 현상**:
  - Qwen2-VL 자체 비전 그라운딩(좌표값)이 활성화되어 `(527,0),(986,314)` 형태의 픽셀 좌표 괄호가 문장에 포함되어 선희 성우가 숫자 좌표까지 읽는 노이즈 발생.
* **조치 내역**:
  - **1차 방어 (Jetson `vlm_service_node.py`)**: `re.sub(r'\([0-9\s,]+\)', '', response)` 정규식을 통해 바운딩박스 괄호 및 좌표를 원천 제거하고, 끝자리 쉼표(`strip(' ,;')`) 제거 및 마침표 보정.
  - **2차 방어 (Pi 5 `speaker_node.py`)**: 수신단에서도 동일한 방탄 정규식을 적용하여 어떠한 상황에서도 좌표가 발화되지 않도록 이중 방어막 구축.
* **최종 실측 발화 검증**:
  - **`[Pi5 Speaker]`**: *"책상 하나, 의자 두 개가 보입니다."* 완벽 출력 확인.
