## 2. 세부 작업 내역

### 2.1 젯슨 Orin Nano (Tier 2) YOLO 초경량화 & 다이어트
- **기존 병목**: YOLO11m 가중치 구동 및 매 프레임 `plot()` CPU 렌더링 + `cv2.imencode()` 재인코딩으로 인해 프레임당 20ms 이상 소모 및 VRAM 1.8GB 점유.
- **개선 조치**:
  1. **0.1ms JSON 바운딩박스/좌표 발행 (`/yolo/detections`)**:
     - `image_size`, `box [x1, y1, x2, y2]`, `center [cx, cy]`, `size [w, h]`, `rel_box [0.0~1.0]`, `conf`, `class_name`을 포함하는 초경량 JSON 스키마 적용.
     - `publish_annotated=False` 기본값 적용으로 시각화 재인코딩 바이패스 (지연시간 20ms 단축).
  2. **YOLO 모델 체급 최적화**:
     - `yolo11m.pt` (39MB, 1.8GB 점유) ➔ **`yolo11n.pt` (5.4MB, 300~450MB 점유)** 로 스위칭.
     - 가용 메모리 **4.8GB ➔ 5.5GB+ 로 대폭 확보**.

### 2.2 관제 노트북 Host PC (Tier 3) 실시간 HUD 뷰어 개발
- **개발 파일**: `src/laptop/yolo_monitor_viewer.py`
  - **스마트 자동 래퍼 탑재**: Mint 호스트에서 실행 시 ROS 2 Humble Docker(`ros2_humble_basic`)를 자동 감지/실행하여 사용자 편의성 극대화.
  - **독립 OpenCV GUI (WINDOW_NORMAL)**: 창 크기 자유 조절 지원, 무거운 `rqt` 완전 대체.
  - **실시간 엔지니어링 HUD**: 수신 FPS, 동기화 지연시간(`Sync Latency ms`), 타겟팅 중심점 십자선 표출.
- **바탕화면 원클릭 바로가기**: `~/바탕화면/jta-yolo-monitor.desktop` 생성 및 신뢰 등록 완료.

### 2.3 라즈베리파이 5 (Tier 1) 풀 화각(Full FOV) 스트리머 교체
- **문제 진단**: 기존 640x480 크롭 모드로 인해 화각이 좁아지는 줌인 현상 발생.
- **개선 조치**:
  1. 기존 구버전 스트리머를 `~/camera_bak/camera_ros2_stream_bak_20261103_093820.py`로 안전 백업.
  2. IMX219 센서 전체를 2x2 비닝하는 **1640x1232 Full FOV ➔ 640x480 다운스케일링** 최적화 스트리머(`src/pi5/camera_ros2_stream_optimized.py`) 배포 및 기동.
  3. 넓은 광각 화각 100% 정상 복구 확인.

### 2.4 젯슨 Orin Nano 엣지 AI & VLM 하드웨어 최적화 (85% 황금 밸런스)
- **TUI(콘솔) 모드 영구 전환**:
  - `sudo systemctl set-default multi-user.target && sudo systemctl isolate multi-user.target`
  - Xorg/GNOME 데스크톱 점유 제거 ➔ **순수 OS 점유율 400MB 수준으로 극단적 다이어트 완료**.
- **16GB NVMe 슈퍼 스왑 에어백 장착**:
  - `/swapfile` 16GB 생성 및 `/etc/fstab` 영구 등록.
  - VLM 메모리 스파이크 시 OOM-Killer 및 커널 패닉 원천 차단.
- **엔비디아 런타임 & VLM 가속 환경 구축**:
  - 기존 검증된 황금 컨테이너(`my_ros2_robot:humble`, PyTorch 2.8.0 + CUDA 12.6 + TensorRT 10.4.0) 활용.
  - `transformers`, `accelerate`, `einops`, `libvips42`, `qwen-vl-utils`, `av` 환경 세팅 완료.
  - **`Qwen2-VL-2B-Instruct` 온디바이스 VLM 벤치마크 및 실시간 추론 성공**:
    - NVMe SSD 캐시 기반 모델 로딩 **10.14초**, 더미 이미지 추론 **2.81초** 달성.
    - **Pi 5 카메라 실시간 프레임(`/camera/image_raw/compressed`) 캡처 ➔ 젯슨 VLM 한국어 시각 분석 성공**:
      - "작업실 내부의 테이블 위 카메라, 스마트폰 및 의자, 가방 등"의 시각적 맥락을 정확하게 12.33초 만에 단독 온디바이스로 서술.
      - 30fps 초경량 YOLO(실시간 반사 회피) + Qwen2-VL(고차원 시각 상황 이해) 하이브리드 파이프라인 실증 완료.
- **하드웨어 모니터링 툴 체계 구축**:
  - Jetson Orin Nano: `jtop 7.2.2` (jetson-stats) 설치 완료.
  - Raspberry Pi 5 & Laptop: `btop` 실시간 시스템/네트워크 관제 툴 가동.
