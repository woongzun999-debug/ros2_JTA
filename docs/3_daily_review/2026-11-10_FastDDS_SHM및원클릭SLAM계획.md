# [작업 일지] 2026-11-10 FastDDS SHM 하이브리드, 젯슨 VLM 4-bit 경량화 및 파이5 Edge-TTS 구축

- **작성일**: 2026-11-10
- **작성자**: `ROS2_JW`
- **대상 시스템**: JTA 3-Tier 로봇 시스템 (Tier 1: Pi 5, Tier 2: Jetson, Tier 3: Laptop)

---

## 1. 금일 작업 요약

금일은 3-Tier 분산 시스템의 통신 병목을 해소하기 위한 **FastDDS SHM(공유 메모리) 하이브리드 트랜스포트**를 구축하고, Jetson Orin Nano의 **Qwen2-VL VLM 4-bit NF4 양자화 경량화(VRAM 1.42GB)** 및 의존성 자산화를 완료하였습니다. 
아울러 Raspberry Pi 5 현장 USB 스피커에 **Microsoft Edge-TTS 선희 성우 보이스**를 장착하여 무인 시각 브리핑 루프를 완성하였으며, 에이전트 하네스 최상위 헌법에 **제0조 행동 인터셉터(Hard Brake Rule)**를 신설 박음질하였습니다.

---

## 2. 세부 엔지니어링 수행 내역

### 1) FastDDS SHM(공유 메모리) 하이브리드 트랜스포트 선언 및 로컬 무결성 검증
* **배경 및 원인 분석**:
  - 기존 `fastdds_unicast.xml`은 `udpv4` 프로파일만 활성화되어 있어, 동일 기기(Pi 5 내부, 노트북 내부) 내 노드 간 통신 시에도 리눅스 커널 네트워크 스택(루프백 UDP)을 타며 불필요한 직렬화/버퍼링 및 수명주기 서비스 응답 지연이 발생함.
* **조치 내역**:
  - `config/fastdds_unicast.xml`에 `<transport_descriptors>`를 신설하여 `SHM` (지연 ~0.001ms, CPU 부하 0%)과 `UDPv4` (3-Tier 무선 피어링)를 하이브리드로 등록.
  - 관제 노트북 도커(`~/ros2_humble_docker/fastrtps_unicast.xml`) 동기화 완료 (`--ipc=host` 연동).
  - 하네스 자동 검증 실행: `scripts/validate_ros2_harness.py` ➔ **PASS 달성**.

### 2) Jetson Orin Nano VLM 4-bit NF4 경량화 실증 및 하네스 자산화
* **VRAM 다이어트 실측 성과**:
  - `Qwen2-VL-2B-Instruct`에 BitsAndBytes 4-bit NF4 + Double Quant 양자화 적용.
  - 순수 VRAM 점유: 기존 5.0GB(FP16) ➔ **1.42GB (4-bit NF4)** 로 **3.58GB(71.6%) 가용 VRAM 즉시 회수**.
  - 추론 속도: 모델 초기 VRAM 상주 11.87초, 1회 질의 지연 시간 **10.80초** 달성.
  - 환각 방지 시스템 프롬프트 가드레일 하에 연구실 주변 환경 정밀 한국어 브리핑 실증 완료.
* **프로세스 공존 및 무인 오토스타트 체계화**:
  - 젯슨 도커 내에서 실시간 YOLO11n(PID 144)과 VLM 4-bit(PID 795)가 메모리 충돌 없이 완벽 동시 상주 (가용 RAM 3.5GB+ 확보).
  - 패키지 빌드 없이 단일 스크립트로 동작하도록 컨테이너 부팅 런처(`/root/ros2_ws/launch_yolo11n.sh`)에 백그라운드 자동 기동(`nohup python3 ... &`) 연동 완료.
  - 런타임 패키지 버전 동결 명세서 작성: `src/jetson/requirements_vlm.txt` 하네스 자산화.

### 3) Raspberry Pi 5 고품질 Edge-TTS 음성 노드 구축 및 오토스타트 연동
* **현장 스피커 분산 음성 파이프라인 완성**:
  - 젯슨의 로컬 오디오 재생을 비활성화하고, Pi 5가 `/vlm/response` 및 `/tts/say` 토픽을 직접 수신하여 꽂혀있는 USB 스피커(`UACDemoV10`, `plughw:0,0`)로 출력하는 순정 ROS 2 분산 구조 정립.
  - **Microsoft Edge-TTS (`ko-KR-SunHiNeural`) 탑재**:
    - 기존 구글 번역기 특유의 기계음과 배속 왜곡을 원천 배제하고, 유튜브/성우 수준의 자연스러운 1.0배속 표준 여성 보이스 장착.
  - **패키지 정식 편입**:
    - `src/pi5/jta_bringup/jta_bringup/speaker_node.py` 신설 및 `robot.launch.py` 마스터 런치 파일에 등록 (`respawn=True`).
    - 실기 테스트 통과: *"선희 성우 노드가 정상적으로 등록되었습니다."* 음성 출력 확인.

### 4) AGENTS.md 최상위 헌법 제0조 (Hard Brake Rule) 신설 박음질
* **제정 사유**:
  - 에이전트가 사용자의 요구사항이나 문제 제기를 받았을 때, 독단적으로 먼저 파일을 수정하거나 원격 명령을 실행하여 발생하는 시간 낭비 및 재작업 비효율 원천 차단.
* **핵심 가드레일**:
  - 파일 수정 및 커맨드 실행 도구 호출 전, 반드시 행동을 멈추고 **[원인 분석 + 2~3가지 선택형 옵션(A/B/C) 제시 + 질문]**으로 형님의 명시적 승인("진행시켜")을 얻은 후에만 착수하도록 헌법화.

## 3. 트러블슈팅 타임라인

### [19:30] FastDDS XML 스키마 검증 및 하네스 피어 누락 에러 해결
* **발생 상황**: FastDDS 하이브리드 선언 초기 작성 시 로컬 루프백(`127.0.0.1`)이 initialPeersList에서 누락되어 하네스 검증에서 `FAIL: 1` 발생.
* **원인 진단**: 하네스 규약 상 `127.0.0.1` 루프백 피어가 명시되어야 내부 통신 폴백 및 로컬 모니터링이 보장됨.
* **조치 내역**: `config/fastdds_unicast.xml`의 `initialPeersList`에 `127.0.0.1`을 최상단으로 복원 재작성 후 재검증 통과 (47 PASS 달성).

### [20:30] Pi 5 스피커 구버전 좀비 프로세스 토픽 가로채기 해결
* **발생 상황**: Edge-TTS 선희 성우 보이스를 배포했음에도 이전 구글 번역기 기계음/남성 톤이 재생됨.
* **원인 진단**: 백그라운드에 이전에 테스트하던 구버전 `speaker_node` 프로세스가 3개 중복 잔류하여 `/tts/say` 토픽을 선점 가로채기 함.
* **조치 내역**: `pkill -9 -f speaker_node`로 잔류 프로세스 전멸 후, `robot.launch.py` 기반 단독 프로세스로 상주시켜 선희 성우 보이스 정상 출력 복구.

### [21:05] FastDDS SHM 트랜스포트 동작으로 인한 Pi 5 내부 CLI 토픽 미표출 규명
* **발생 상황**: 노트북 관제소에서는 모든 센서/영상 토픽이 정상 수신되나, Pi 5 내부 터미널에서 `ros2 topic list` 조회 시 토픽이 2개만 보이는 현상 발생.
* **원인 진단**: `config/fastdds_unicast.xml`에 SHM(공유 메모리) 트랜스포트를 적용함에 따라 동일 기기 내부 노드 간 통신이 커널 네트워크(UDP)가 아닌 `/dev/shm` RAM 세그먼트로 격리되어 동작함. 일회성 CLI 세션이 백그라운드 상주 런처의 SHM 세그먼트와 즉각 동기화되지 못하여 발생한 정상적인 SHM 격리 특성임을 형님께서 정밀 규명.
* **조치 내역**: 외부 관제 노트북 및 기기간 통신은 UDPv4 유니캐스트로 정상 작동함을 교차 검증 완료.
