## 2. 세부 작업 내역

### 2.1 WebUI(:9999) 실시간 YOLO 인식 확률(Confidence) 복구
- **문제 진단**:
  - `web_monitor_server.py`에서 JSON 파싱 시 `o.get('confidence', 0)`을 조회했으나, `jetson_yolo_node.py`는 `"conf"` 키로 발행하여 웹 상에서 항상 `(0%)`로 고정 출력됨.
- **조치 내역**:
  - `o.get('conf', o.get('confidence', 0))` 이중 폴백 처리로 실시간 확률(`chair (86%), cup (74%)`) 정상 렌더링 복원.
  - 컨테이너 잔류 백그라운드 프로세스 충돌 방지 클린 재기동 완료.

### 2.2 비전 스트리밍 시야 확보 및 화면 잘림 완전 해소
- **문제 진단**:
  - 영상 내부 좌우 하단에 오버레이 태그(`[감지: ...]`, `[FastDDS Unicast]`)가 떠서 바닥 장애물 시야를 가림.
  - `min-h/max-h` 높이 제한으로 인해 브라우저 창 크기에 따라 4:3(640x480) 카메라 영상 위아래가 잘리는 현상 발생.
- **조치 내역**:
  - 영상 내부의 모든 오버레이 태그를 영상 바깥 하단 상태 바로 영구 분리.
  - 뷰포트 컨테이너를 **`aspect-[4/3]` 정비율**로 고정하여 상하좌우 1픽셀도 잘림 없이 100% 온전하게 표출되도록 개편.

### 2.3 YOLO 바운딩 박스 타이트 피팅 & 라벨 스마트 플립
- **조치 내역**:
  - 바운딩 박스를 중심점 기준 **8% 타이트 축소 (`SCALE = 0.92`)** 하여 물체에 정확히 밀착.
  - 객체가 화면 맨 위에 있을 때 라벨이 화면 위 음수 영역으로 잘리던 문제를 **박스 안쪽(아래)으로 자동 전환(Flip)**되도록 처리.
  - 박스 테두리 선(두께 2px)이 화면 끝선에 묻히지 않도록 안전 마진(`max(2, min(w - 3, ...))`) 클램핑 적용.

### 2.4 Jetson VLM 현황 진단 및 헌법(AGENTS.md) 제정
- **현장 실측 결과**:
  - Jetson Orin Nano(`/root/ros2_ws/models/`)에 `Qwen/Qwen2-VL-2B-Instruct` (FP16 원본 Safetensors 4.2GB) 가중치 완비 확인.
  - 현재 FP16 구동 시 VRAM 4.8GB~5.2GB 점유로 추가 노드(Nav2, 3D 매핑) 탑재 공간 부족 진단.
- **규약 제정 및 로드맵 수립**:
  - **Moondream2 영구 배제**: `my_ros2_robot:humble` (Ubuntu 22.04 + CUDA 12.6 + PyTorch 2.8.0) 환경과의 라이브러리 심각한 충돌 및 ROS 2 파괴 문제로 영구 배제 헌법화.
  - **VLM 환각(Hallucination) 절대 금지**: 보이지 않는 사물 추측 금지, 화면 팩트 기반 서술 시스템 프롬프트 가드레일 강제.
  - **Qwen2-VL 4-bit 양자화 로드맵 등재**: VRAM 5.0GB ➔ 2.0GB (2.7GB 회수)로 3.5GB+ 순수 VRAM을 확보하여 추가 ROS 2 노드 구동 기반 마련.
