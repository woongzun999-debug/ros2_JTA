- **실기 배포·검증**: `sync_to_robot.sh jetson` 동기화 후 Jetson `ros2_humble_dev` 컨테이너 내 `vlm_service_node.py` 재시작 완료 (`PID 155658`).

## 2. 기술 검토 및 아키텍처 의사결정 (차기 고도화 분석)
- **단안 RGB 카메라 기반 낮은 장애물(의자 다리 등) 회피 방향**:
  - 2D LiDAR 사각지대 보완은 단순 클래스 라벨링(`YOLO`)만으로 해결되지 않으며, 3D 거리/바닥 좌표를 **Nav2 `local_costmap` 가상 장애물**로 반영해야 함을 정리 (`yolo11m` 체급 상향만으로는 COCO 미정의 부품 인식 불가 및 Jetson VRAM 부담 가중).
  - 대안 비교: **루트 A**(경량 단안 Depth 추정 + 가상 스캔 → 범용 회피) vs **루트 B**(커스텀 YOLO 박스 하단 픽셀 바닥 투영 → 얇은 다리 정밀 점 찍기) vs **루트 C**(Depth 카메라 장착).
- **상용 AMR(로보락) 대비 4대 격차 & Nav2 로컬 컨트롤러 비교**:
  - 4대 격차 도출: ① 사각지대 3D 센서 퓨전 ② 이동 시 자동 위치 찾기/맵 갱신 ③ 자율 도킹 ④ 좁은 공간 탈출·모션 부드러움.
  - 2번(AMCL `recovery_alpha` + `recoveries_server` 실기 정정)은 금일 선반영 완료.
  - 4번(로컬 컨트롤러 교체 검토) 3종 장단 정리: **`DWB`**(현행, 점수 가중치 진동/후진 불가) vs **`RPP`**(커브·근접 자동 감속, Pi 5 초경량) vs **`MPPI`**(좁은 틈·모션 최강, Pi 5 CPU 점유 검증 필요).
