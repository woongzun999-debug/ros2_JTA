## 4. 📋 작업장 현장 방문 시 즉시 수행할 작업 리스트 (Next Action)

내일 작업장에 실물 로봇(Pi 5 & Jetson)이 준비되었을 때 순서대로 수행할 정밀 엔지니어링 작업 목록입니다:

### 1) 맵 데이터 원천 전송 (노트북 ➔ Pi 5 로컬 주권 확립)
* **목적**: Pi 5가 자기 디스크(`<PI_HOME>/maps/`)에 지도를 직접 들고 있어야 완전한 단독 폐쇄 루프 주행이 가능.
* **명령어**:
  ```bash
  # 노트북 ➔ Pi 5 로컬 맵 디렉토리로 실측 지도 복사
  ssh <PI_USER>@<PI5_IP> "mkdir -p ~/maps"
  scp maps/my_map.* <PI_USER>@<PI5_IP>:~/maps/
  ```
* **Pi 5 메타데이터 경로 확인**:
  - `my_map.yaml` 파일 내 `image: <PI_HOME>/maps/my_map.pgm` (Pi 5 로컬 경로) 정상 표기 여부 확인.

### 2) `scripts/save_map.sh` 아키텍처 순리 복원 (Pi 5 원천 저장 ➔ 노트북 백업 Pull)
* **기존 문제**: 노트북 도커에서 지도를 먼저 저장하던 역주행 구조.
* **개선 작업**:
  1. Pi 5 로컬에서 `ros2 run nav2_map_server map_saver_cli -f ~/maps/<map_name>`을 실행하여 **Pi 5에 원본 1순위 저장**.
  2. 저장이 완료되면 `scp`로 노트북의 `maps/` 디렉토리에 **단순 백업(Pull) 복사**하도록 스크립트 수정.

### 3) Pi 5 단독 폐쇄 루프 Nav2 자율주행 실증
* **순서**:
  1. **Tier 1 (Pi 5)**: `bash scripts/run_pi5_nav2.sh` 실행 (Headless로 Map Server, AMCL, Costmap, Planner, Controller 기동).
  2. **Tier 3 (노트북)**: `bash scripts/run_rviz.sh nav2` 실행 (Nav2 전용 3D 뷰어 오픈).
  3. **초기 위치 캘리브레이션**: RViz2 상단 `2D Pose Estimate`로 로봇의 현재 위치와 방향 클릭 ➔ AMCL 파티클 수렴 확인.
  4. **자율주행 하달**: `Nav2 Goal`로 목표 지점 지정 ➔ 로봇 실물 바퀴가 경로 추종하며 주행하는지 실증.
  5. **노트북 제로 의존성 검증**: 주행 중 노트북 Wi-Fi를 끄거나 화면을 덮어도 로봇이 혼자서 목적지까지 안전하게 도착하고 장애물을 회피하는지 검증.
